
## Overview

This project uses **Python and pandas** to analyse a taxi-trip dataset. It focuses on data cleaning, filtering, aggregation, time-based analysis, fare comparison, and trip-chain construction.

## Main Tasks

- Extract trips longer than 50 distance units.
- Identify trips with missing payment information.
- Count trips by pickup and drop-off location.
- Separate rows with missing essential values into a `bad` dataframe.
- Calculate trip duration.
- Count trips by pickup location.
- Group pickup times into 30-minute intervals.
- Calculate average passengers and fares by interval.
- Analyse fares and tip-to-fare ratios by payment type.
- Find the pickup location with the highest average fare.
- Identify the five most common destinations for each pickup location.
- Compare common-destination fares with overall fares.
- Build chains of consecutive trips.
